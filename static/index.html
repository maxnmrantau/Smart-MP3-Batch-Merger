Panduan Penggunaan Smart MP3 Batch Merger

Panduan lengkap pengoperasian, pengaturan folder manual, dan fitur cerdas aplikasi

Langkah 1

Input Lagu Wajib & Lagu Random

Klik tombol "Pilih Folder Wajib" untuk memilih folder berisi lagu utama (contoh: Lagu Pembuka/Intro/Identitas). Kemudian klik "Pilih Folder Pool" untuk folder kumpulan lagu yang akan diacak secara cerdas.

✨ Anda juga bisa mengklik "Pilih File Lagu" atau menarik (Drag & Drop) file MP3 langsung ke kotak input.
Langkah 2

Tentukan Mode & Posisi Lagu Wajib

Pilih di mana posisi Lagu Wajib akan ditempatkan di setiap file output:

  • Di Awal (Intro): Lagu wajib selalu menjadi lagu pembuka (#1) di setiap file MP3.
  • Di Akhir (Outro): Lagu wajib selalu ditaruh di slot lagu paling terakhir.
  • Posisi Acak: Lagu wajib dipastikan masuk, namun urutan slotnya diacak alami.
Langkah 3

Atur Komposisi & Jumlah File Output

Gunakan slider interaktif untuk menyesuaikan:

  • Panjang Lagu per Output: Jumlah lagu dalam 1 file gabungan (misal: 5 lagu = 1 Wajib + 4 Random).
  • Target Jumlah File Output: Berapa buah file MP3 baru yang ingin dibuat (misal: 10 buah file MP3 unik).
  • Efek Transisi (Crossfade): Geser slider jika ingin ada efek fade-in/fade-out halus antar lagu.
Langkah 4

Tentukan Folder Simpan & Mulai Merge

Pilih folder tujuan di bagian "3. Folder Penyimpanan Hasil", lalu klik tombol hijau "Mulai Proses Merge (Batch)". Progress bar dan urutan lagu yang sedang digabung akan ditampilkan secara live.

🛡️

Aplikasi Bersih Tanpa Folder Otomatis (Clean Workspace)

Aplikasi ini TIDAK MEMBUAT FOLDER OTOMATIS di tempat file .exe berada saat dibuka. Direktori komputer Anda akan tetap rapi dan bersih 100%.

Cara Mengatur Folder Secara Manual:

1
Lagu Wajib (Mandatory):

Pada kotak nomor 1, klik "Pilih Folder Wajib" lalu arahkan ke folder musik Anda di drive mana saja (contoh: D:\Koleksi Lagu\Intro).

2
Pool Lagu Random (Acak):

Pada kotak nomor 2, klik "Pilih Folder Pool" lalu arahkan ke folder kumpulan lagu acak Anda (contoh: D:\Koleksi Lagu\All Tracks).

3
Folder Penyimpanan Hasil (Output):

Pada kotak nomor 3 di bawah, klik "Pilih Folder Output" dan tentukan di mana file MP3 hasil gabungan ingin disimpan (contoh: D:\Hasil Podcast Mix).

🔀

Mode Giliran Lagu Wajib

Jika Anda memasukkan lebih dari 1 lagu di folder Lagu Wajib:

  • Semua Wajib Masuk: Setiap file hasil merge akan memuat seluruh lagu wajib tersebut sekaligus.
  • Ambil 1 Bergilir (Rotasi): Setiap file hasil merge hanya mengambil 1 lagu wajib secara bergantian (File 1 = Lagu Wajib A, File 2 = Lagu Wajib B, dst).
🧮

Live Combinatorics & Anti-Duplikasi

Di panel kanan, sistem menghitung kemungkinan kombinasi unik secara matematis:

  • 100% Anti-Duplikasi: Sistem menggunakan cryptographic hash untuk memastikan tidak ada 2 file MP3 dengan urutan lagu yang sama persis dalam 1 batch proses.
  • Laporan Playlist: Setiap selesai proses, file playlist_summary.txt akan disimpan otomatis di folder output untuk merekam daftar lagu di setiap file.
🎵 Kualitas Audio

Auto Match Source Quality

Secara default, aplikasi memindai bitrate lagu asli Anda dan menyesuaikan bitrate output secara otomatis (hingga 320 kbps) sehingga kualitas suara tetap jernih dan original (*lossless quality*).

⚡ Kecepatan Proses

Crossfade vs Sambung Cepat

Jika slider Crossfade diatur ke 0.0 Detik, proses penggabungan audio akan berjalan sangat cepat (*blazing fast*). Jika diatur 1–5 detik, FFmpeg akan melakukan mixing fade transisi halus.

🎧 Pemutar Audio Bawaan

Preview Langsung

Setelah selesai, Anda bisa langsung memutar file MP3 hasil merge di pemutar audio bagian bawah layar tanpa perlu membuka aplikasi luar.
